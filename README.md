A program that writes one funny line from a hopeless tech-support agent to a desperate customer — the classic "turn it off and on again", twisted: if that fails, the agent escalates you to a supervisor who asks the exact same thing, but in a deeper voice.

## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), prints it, and refuses to write anything outside the 1–199 character single-line gate.
